Deploy CrownRace

This page deploys the single Agent Crown Race contract (Crown Race Pass, CROWN) from your own wallet. The constructor takes one argument — the Binance Agent ID (.ai) registry — and it is prefilled below with the real SPACE ID contract for BNB mainnet. The mint starts closed: this page never opens it automatically, nobody can mint until you open it yourself in step 04. Every transaction is signed in your wallet; this page never asks for a seed phrase or private key.

01

Connect wallet

Connect the wallet that should own the contract. The page switches your wallet to BNB Chain mainnet (chain 56) automatically, adding the network first if your wallet does not have it yet.

02

Deploy CrownRace

The daily crown competition: 2,222 Crown Passes, the first 500 free for Agent ID holders (1 per wallet), then 0.0007 BNB per pass. Boosts (0.00015 / 0.0005 / 0.0015 BNB) buy race points; each day's winner takes 50% of that day's boost pool at settle, the owner keeps 50%.

The contract's constructor takes one argument — the Agent ID registry the mint gate checks. For BNB mainnet it must be the SPACE ID .ai contract, prefilled here. Check it before you deploy; it is immutable once deployed.

03

Set base URI

tokenURI(id) returns baseURI + id + ".json". The field below is prefilled with the real metadata URL — all 2,222 pass metadata files (1.json … 2222.json) and their SVG artwork are already published under https://crownrace.site/metadata/, so you can set it as-is right after deploying (it must end with "/"). Minting, boosting and settling all work without it; this only names where pass artwork metadata lives.

Waiting — deploy CrownRace first.

04

Open / close mint (owner only)

Minting starts closed when CrownRace is deployed — nobody can mint until the owner opens it. Open it here when you are ready to launch, and close it again any time the same way. Only the owner wallet can do this; the contract rejects everyone else.

Waiting — deploy CrownRace first.

05

Race controls

Settle day: closes the oldest unsettled day, pays that day's points leader 50% of its boost pool, and credits the other 50% to the owner balance. It is permissionless — anyone can call it, including a holder's agent — but the button is here so the owner can settle too. If several idle days passed, call it once per day until it catches up. Pause / unpause boost is owner-only and stops new boosts while paused; settling and minting are unaffected.

Waiting — deploy CrownRace first.

06

Withdraw owner balance (owner only)

The owner balance holds the owner's 50% share of every settled day pool, plus every paid-pass payment (0.0007 BNB each). Withdraw sends the whole balance to the owner wallet. An unsettled day's pool can never be withdrawn — it stays locked until that day is settled.
